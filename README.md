# Backend

A Node.js + Express backend project with TypeScript, Mongoose, and other helpful middleware for building RESTful APIs.

## 🛠 Tech Stack

- **Node.js**
- **Express**
- **TypeScript**
- **Mongoose** (MongoDB)
- **Middleware**: `cors`, `compression`, `body-parser`, `cookie-parser`
- **Dev Tools**: `nodemon`, `ts-node`

---

## 🚀 Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (v18+ recommended)
- [MongoDB](https://www.mongodb.com/) (local or Atlas)

### Installation

Clone the repo and install dependencies:

```bash
git clone https://github.com/your-username/backend.git
cd backend
npm install
npm start
```
